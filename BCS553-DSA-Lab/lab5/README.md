## Aim
Search for a value one element at a time.

## Theory
- **Linear (sequential) search** checks elements one by one from the start until the key is found.
- It returns the **index** if found, otherwise **-1**.
- It works on **unsorted** data.
- Time: best case **O(1)** (first element), worst case **O(n)**. Space: O(1).
- Counting how many times a value appears needs a full traversal.
