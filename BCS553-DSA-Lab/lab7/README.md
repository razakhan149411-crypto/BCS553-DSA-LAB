## Aim

## Theory
- **Search with break:** once the key is found, `break` stops the loop so no time is wasted.
- Printing a message depends on whether the stored index is still `-1`.
- Sorting a small array with bubble sort works the same as in Lab 3.
- **Product:** like the sum, but start the variable at **1** (not 0) and multiply.
- **Filtering:** use the remainder operator, `a[i] % 2 == 0` is true for even numbers.
